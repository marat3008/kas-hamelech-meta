# Messaging Framework

The system for generating on-brand copy. Combine a **core value prop** + an **angle** + a **proof point** + **one clear CTA**, filtered through the audience rules in `brand/audience-shabbat-observant.md`.

## The message equation

```
HOOK (stop the scroll)  →  VALUE/ANGLE (why it matters to them)
   →  PROOF (why believe us)  →  CTA (one next step, usually WhatsApp)
```

Keep it short. Hebrew-first. One idea per ad.

## Core value props (pick one to lead)

| # | Value prop | One-line Hebrew expression |
|---|---|---|
| V1 | Bespoke / made-to-order | `כיסא שנבנה בדיוק בשביל השולחן והבית שלכם.` |
| V2 | Real craftsmanship / handmade | `עבודת יד אמיתית — מסגרת מחוזקת, בד לבחירתכם.` |
| V3 | Built for family life & guests | `בנוי לעמוד בשולחן שבת גדול, שבוע אחרי שבוע.` |
| V4 | Heirloom / for generations | `רהיטים שנשארים במשפחה. לדורות.` |
| V5 | Honor of the table (kavod) | `הכבוד שמגיע לשולחן השבת שלכם.` |

## Angles (the emotional entry point)

- **A1 — Kavod Shabbat:** the Shabbat table deserves seating worthy of it. ("שבת המלכה — וכיסאות ראויים לה.")
- **A2 — Hosting / hachnasat orchim:** receive your guests in comfort and dignity.
- **A3 — Chag readiness (seasonal, urgency):** order now, ready in time for [Chag]. *(Requires confirmed lead time.)*
- **A4 — Restore, don't replace (reupholstery):** give the chairs you love a second life. Before/after.
- **A5 — Made for your space:** exact size, your fabric, your colors.
- **A6 — Craft fascination (top-funnel/TikTok):** watch a chair being made by hand.

## Proof points (make claims believable — from `product-catalog.md`)

Handmade upholstery · reinforced frame for heavy family use · customer-chosen fabric & color · made to exact dimensions · reupholstery capability (heirloom) · direct-from-the-maker · studio visits · [confirm: warranty, lead time, made-in-Israel].

## CTAs (always exactly one)

- `שלחו לנו הודעה בוואטסאפ ונבנה לכם הצעה →` (primary — Click-to-WhatsApp)
- `לתיאום ביקור בסטודיו — הקליקו` (studio visit)
- `רוצים לראות דוגמאות? כתבו לנו "כן"` (catalog request — matches existing WhatsApp flow)
- `קבלו הצעת מחיר אישית` (Lead Ad)

## Objection → answer map

| Hesitation | Message that defuses it |
|---|---|
| "Too expensive" | Heirloom framing: cost-per-year over decades; reupholster instead of replace; *do it once, do it right*. Never discount. |
| "Won't be ready for the Chag" | State the lead time and the "order by" date plainly; offer a studio visit now to lock the slot. |
| "Can I trust the quality?" | Before/after proof, craftsmanship close-ups, testimonials, studio visit, warranty, direct-from-maker. |
| "Too many decisions (fabric/size)" | "We guide you step by step" + studio visit + we come measure. Reduce the decision to one WhatsApp message. |
| "I'll do it later" | Seasonal urgency tied to a real Chag deadline; limited production slots. |

## Tone guardrails (recap)

- Warm, respectful, confident — never salesy or discount-shouty.
- Religious references sincere and correct, never gimmicky.
- Modesty (tzniut) in imagery, especially Haredi-facing.
- One idea, one CTA, short lines. Hebrew-first.

## Hook bank (for the first line / first second)

- `הכיסא הזה נבנה ביד. תראו איך.` (craft)
- `שולחן השבת מוכן — חסר רק דבר אחד.` (kavod/hosting)
- `לפני ואחרי: אותו כיסא, חיים חדשים.` (reupholstery)
- `כמה אורחים ישבו סביב השולחן שלכם השבת?` (hosting question)
- `רהיט אחד. שלושה דורות.` (heirloom)
- `עוד מעט החגים. השולחן שלכם מוכן?` (seasonal)
