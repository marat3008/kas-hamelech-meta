# 🧪 Experiments Registry

Every deliberate test — creative, angle, audience, offer, timing, budget — gets a row. Register it when it starts; fill the verdict when it ends. Fold winners back into the source KB files (see `README.md`).

## How to run a clean test
- **Change one variable at a time** (angle *or* audience *or* creative — not all three).
- Give it enough spend/time to exit the learning phase (~50 events/wk) and reach ≥100 clicks before judging.
- Pre-declare the **decision metric** (usually cost per WhatsApp conversation / CPL, read alongside close rate).
- Keep Shabbat/Chag pauses identical across variants so they don't skew the comparison.
